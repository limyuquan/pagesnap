Click the Page Snap icon in the toolbar.

The whole page, not just the screen.

It scrolls and stitches for you, one screen at a time, then puts the page back the way you left it. Press Esc to stop early and keep what it has.

  • Sticky headers show up once, not on every screen.
  • Chat bubbles and cookie bars stay where they belong.
  • Lazy images load before their screen is taken.
  • Apps that scroll in a panel are expanded to their full length.

Stays on your machine.

No account, no uploads, no network requests. Captures live in your browser’s storage and nowhere else. Chrome shows no warning when you install it.

Install it from source.

Page Snap isn’t on the Chrome Web Store yet. Building it takes a minute and needs Node.js 22 or newer.

  1. Build

    git clone https://github.com/limyuquan/pagesnap.git && cd pagesnap
corepack enable && pnpm install && pnpm build

  2. Load

    Open chrome://extensions, turn on Developer mode, click Load unpacked and choose pagesnap/.output/chrome-mv3. On a Mac, ⌘⇧. shows the hidden .output folder in the file picker.

  3. Pin

    Pin Page Snap to the toolbar. Click it on any page, or press Alt Shift P. To update later, run git pull && pnpm build and click reload on its card.
