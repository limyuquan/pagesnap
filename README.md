# Page Snap (`pagesnap`)

Chrome extension: full-page screenshot → annotate instantly (arrows, boxes, underline, highlight,
pen, text) → `Cmd+C` the marked-up image into an AI chat.

Status: v0.1 in progress. Plan: [docs/PLAN.md](docs/PLAN.md). Ownership, contracts and commands:
[docs/CONTRACTS.md](docs/CONTRACTS.md). Quick start: `pnpm install && pnpm check && pnpm test:e2e`.

Prior art: [mrcoles/full-page-screen-capture-chrome-extension](https://github.com/mrcoles/full-page-screen-capture-chrome-extension)
(MIT, MV2, 2016). It's a reference only; no code has been copied yet.
